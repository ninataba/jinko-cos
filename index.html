/ QUICKSTART

Two lines. Real execution.

Drop Jinko into any MCP-compatible agent — Claude Desktop, the Vercel AI SDK, or your own runtime.

import { experimental_createMCPClient as createMCPClient, generateText } from 'ai';

// 1. Connect the Jinko MCP server
const jinko = await createMCPClient({
  transport: { type: 'stdio', command: 'npx', args: ['@jinko/mcp-server'] },
});

// 2. Hand its tools straight to your agent — search, book, pay
const { text } = await generateText({
  model: claude('claude-sonnet-5'),
  tools: await jinko.tools(),
  prompt: 'Book the cheapest direct flight SFO→JFK next Tuesday.',
});

// → returns a real PNR. No browser. No scraping. ~500 tokens.
